# Technical Research — NEXUS AI

Research snapshot: 2026-11-05. This is an initial source register, not a claim that every API/version has been fully validated. Re-check official documentation before pinning dependencies or implementing provider-specific behavior.

## Retrieval design

Initial design: tenant-scoped PostgreSQL rows, pgvector dense retrieval and PostgreSQL full-text lexical retrieval. Fuse ranked lists using Reciprocal Rank Fusion (RRF), then optionally rerank a bounded candidate set. Apply organization, workspace, document and user permissions before any chunk reaches the model. Preserve source document ID, version, page, section and chunk identifiers to validate citations.

Do not assume approximate HNSW search always yields the best recall or that a vector index itself enforces authorization. Compare exact search with approximate search on a labelled corpus and test filters under realistic tenant cardinalities.

## Agent design

Use a supervisor-controlled LangGraph workflow with a small number of deterministic nodes. Persist execution state and approval interrupts. The LLM must not receive unrestricted shell, SQL, filesystem or network tools. Each tool has a schema, permission check, timeout, bounded output, audit event and idempotency strategy where writes are allowed.

## Evaluation design

Keep a versioned synthetic test corpus and labelled questions. Report Recall@K, Precision@K, MRR and nDCG for retrieval; citation precision/coverage, faithfulness and abstention for answers; routing/tool argument/permission correctness for agents; and latency, token usage and error rate for operations. Keep deterministic tests separate from LLM-judge scores. Never publish benchmark numbers until the runner has actually executed against a named dataset and configuration.

## Limitations of this research snapshot

- This source register is a design baseline, not a full systematic literature review.
- Job descriptions are snapshots and vary by employer, seniority and location.
- No performance, accuracy, security or cost claims are made for the current code scaffold.
